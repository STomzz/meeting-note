# 真机回归清单（发版前跑一遍）

> 环境：Android 手机 + **校园网**（能访问 `YOUR_SERVER_IP:8000`）。App 版本号记录在 `pubspec.yaml`。

## 0. 准备

- [ ] 手机安装最新 APK：`dist/bnu-meeting-<版本>.apk`
      - 这是 **正式签名** 的包；若手机上装的是更早的 debug 签名版，**必须先卸载重装**（本地会议数据会清空，
        需要时先在旧版里导出 Word），之后所有正式签名版本都能直接覆盖升级
- [ ] 设置页：BNUAPI 地址 `https://chatapi.bnu.edu.cn/v1` + 自己的 Key → **测试连接** → 显示「连接成功，共 N 个模型可用」
- [ ] 首次进入录音页时允许 **麦克风** 权限；Android 13+ 还会弹 **通知权限**（用于锁屏录音状态），建议允许

## 1. 录音与分段（核心）

- [ ] 开始录音后，说 3~5 句话，中间停顿 1 秒以上 → 每停顿一次出一段文字
- [ ] 连续说话 45 秒不停顿 → 到 45 秒自动切段（不会丢内容）
- [ ] 录音页进度条随说话音量变化
- [ ] 首段文字出现的时间 ≤ 10 秒（网络正常时）

## 2. 锁屏 / 后台（本轮新增）

- [ ] 录音中按电源键锁屏，等 3 分钟再解锁 → 分段与文字仍在继续增加
- [ ] 锁屏期间下拉通知栏 → 通知显示「正在录音」+「已转写 N 段 · 时长」
- [ ] 点通知栏「停止录音」→ 回到 App 后录音已停止并跳到会议详情
- [ ] 录音中切到其他 App（微信等）→ 回来仍在录，段数没断
- [ ] 锁屏时**没有**开「保持屏幕常亮」也不会中断（默认设置）
- [ ] 若锁屏后仍会中断：进系统设置把本 App 加进「电池优化白名单 / 允许后台运行 / 允许自启动」
      （小米 HyperOS、华为 HarmonyOS、OPPO/vivo 等国产 ROM 默认会限制后台麦克风）

## 3. 转写编辑与纪要（本轮新增）

- [ ] 详情页「转写」tab → 每段右侧有播放和编辑按钮
- [ ] 编辑某一段的人名 → 保存后文字已更新；重启 App 后仍在
- [ ] 若已生成过纪要，编辑后出现「转写内容已修改，建议重新生成纪要」提示
- [ ] 「生成纪要…」弹层：填 标题 / 日期 / 参会人（用顿号或逗号分隔）/ 附加要求 → 生成成功
- [ ] 再次打开弹层 → 上次填的抬头信息已自动带出
- [ ] 导出的 Word 里含 会议标题、日期、参会人

## 4. 声音试听（本轮新增）

- [ ] 点某段播放按钮 → 能听到该段录音，进度条走字
- [ ] 播放中再点同一段 → 暂停；再点 → 继续
- [ ] 一段播完自动播下一段；最后一段播完自动停止
- [ ] 播放中点进度条右侧「停止」→ 停止播放
- [ ] 播放某段时，列表里该段高亮

## 5. 导入已有 WAV（本轮加限流）

- [ ] 导入一个 ≥ 30 分钟的 WAV → 全部切块上传成功，无「转写失败」
- [ ] 导入期间观察：请求不再撞 429（若日志有 429，应自动退避重试而不是失败）

## 6. 导出与分享

- [ ] 「导出 Word」→ 系统分享面板 → 发到微信/邮箱，文件能正常打开（含中文字体）
- [ ] 「导出 Word（含转写全文）」→ 文末附完整转写

## 7. 异常与边界

- [ ] 飞行模式下录音 → 分段仍本地保存；恢复网络后点「重试」能补上转写
- [ ] 设置页填错 Key → 转写失败提示「上游鉴权失败（Key 无效或无权限）」，不无限重试
- [ ] 删除会议 → 列表消失，重新进入不再出现（音频文件一并删除）
- [ ] 达到上游限流（10 请求/分钟）时导入长音频 → 自动排队重试，最终全部成功

## 8. 性能

- [ ] 1 小时会议：手机电量消耗在可接受范围（前台服务 + 屏幕默认熄灭）
- [ ] 段数与文字量很大时，详情页滚动不卡顿
- [ ] 录音全程无明显发热/掉帧

## 已知限制（不是 bug）

- App 从最近任务里划掉 → 录音会停止（前台服务随任务结束）
- 部分国产 ROM（小米/华为/OPPO/vivo）默认限制后台麦克风：锁屏仍中断时，需把 App 加入
  电池优化白名单 / 允许后台运行
- 转写为准实时（按停顿分段），不是逐字流式
- 说话人分离不做；只支持 WAV 输入
