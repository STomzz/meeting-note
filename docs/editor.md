# 笔记编辑器：所见即所得（块编辑）

> 目标：正文**默认显示排版后的样子**（不显示 `#`、`-` 这些 md 原文），点一段就能改，改完立刻回到排版。
> 关键约束：**只替换被编辑的那一块**——会议笔记里的 `/v` 引用行、`> 🎙 转写` 块、
> `## 会议纪要（AI 整理）` 都必须逐字节保留（第三方 md 编辑器常见的「顺手重排」在这里是致命的）。

## 三种形态

工具栏右侧的开关切换，选择记在 localStorage `bnu-notes-editor-mode`：

| 形态 | 说明 |
| --- | --- |
| **编辑**（默认） | `BlockEditor`：正文按块渲染，点段落进入编辑（无边框，只有光标闪）；输入 `#` / `##` 弹块类型菜单、`/v` 弹录音选择器 |
| **预览** | 同一个 `BlockEditor` 的只读形态（`editable=false`）：排版后直接读，点段落不会误进编辑 |
| **源码** | 原来的 textarea：直接改 markdown 原文，支持行首 `/v` 弹录音选择器（Ctrl+S 保存不变） |

三种形态共用同一份内容（`stores/notes.ts` 的 `content`），自动保存、问答定位、录音引用插入都走同一条路；
早先版本存的 `wysiwyg` 会兼容读成「编辑」。

## 块模型（`src/core/blocks.ts`）

- **块** = 一段连续的非空行；**空行**、**代码围栏**（``` / ~~~）、**`/v` 引用行**各自成块。
  空行块与围栏块不可编辑（空行块只用于还原原文）。
- 不变式：`joinBlocks(splitBlocks(md)) === md`（任何输入都逐字节相等，含尾随换行），单测里用会议笔记样例、
  代码围栏、表格、没闭合的围栏等一堆输入验证。
- `replaceBlock(blocks, id, text)` 只换目标块（新文本里有空行会再切块）；**未改动的块 id 与文本都不变**
  （id 是编辑句柄，稳定才能「提交完立刻点另一段」）。
- 其它：`appendBlocks` / `insertBlocksBefore` / `insertParagraphAfter` / `dropBlock` /
  `dropBlockTidy`（删一行后把并到一起的空行合成一个，「⋯ → 删除引用」用）。

## `/v` 录音选择器（源码模式与块编辑共用）

候选列表在 `src/core/refPicker.ts`（两边共用同一套排序与过滤，避免两处逻辑漂移）：

- 排序：**本笔记音频目录的** → 别的笔记的；同档里**没引用过的** → 已引用；再按修改时间新 → 旧；
- 过滤：按 `目录/文件名` 子串（大小写不敏感），最多显示 8 条；
- 每行显示 `已引用 / 未引用` 标签、`目录/文件名`、时长；`↑↓` 选、`Enter` 插入、`Esc` 关掉（只关弹层，不退出编辑）；
- 选中的那一刻，把正在输入的 `/v …` 整段换成完整引用行 `/v <相对路径>`（块里其余文字不动）。

块编辑里引用行渲染成播放器，行右侧有个 `⋯`（桌面悬停出现、触屏常显）：

| 菜单项 | 行为 |
| --- | --- |
| **删除引用（音频文件保留）** | 只删文档里这一行 `/v`（用 `dropBlockTidy` 合并相邻空行），**不动** `会议音频/` 下的 wav |
| **复制音频路径** | 复制 vault 相对路径（粘到资源管理器 / `ffmpeg` 命令里能用） |

## 交互（`src/components/BlockEditor.vue`）

| 操作 | 行为 |
| --- | --- |
| 点某一段 | 进入编辑；输入框里是**这一段**的原文（无边框、背景透明，只有光标闪），其它段保持排版 |
| 编辑态字号 | 按块类型走（`k-h1` / `k-h2` / `k-h3` / `k-ul` / `k-ol` / `k-quote` / `k-code`），和渲染结果一致，不跳字 |
| 编辑态高度 | 输入框高度跟着**折行之后**的内容长（`autosizeTa`，进编辑 / 每次输入 / 文档宽度变化都重算）——长行折行时不会把行首顶出去 |
| 空段里输入 `/v`、`/video` | 弹出录音选择器（见上节） |
| 点别处 / `Ctrl+Enter` | 写回（内容变了才发 `update:content`） |
| `Esc` | 取消本次编辑，不发内容 |
| `Enter`（单行） | 以光标为界拆成两段；列表 / 引用自动续标记；只写了标记（`- `、`1. `、`# `）则退出标记变普通段落 |
| 空段里输入 `#` / `##` / `/` | 弹出块类型菜单：正文 / 一级标题 / 二级标题 / 三级标题 / 项目符号 / 有序列表 / 引用 / 代码块（↑↓ 选，Enter 应用） |
| 第一次进编辑 | 下方露一次操作提示（8 秒后自己消失，之后不再打扰） |
| `＋ 新起一段` | 文末新起段落 |
| 拖选文字 | 不进编辑（方便复制）；播放器、链接、按钮的点击也不进编辑 |
| 问答/图谱点引用 | `locate()` 滚动到目标块并高亮 1.8 秒 |

## 引用插入落点

录音面板 / 会议面板插入 `/v` 时（`insertLines`）：

1. 正在编辑某段 → 插到**那段之后**；
2. 否则若存在 `## 会议纪要（AI 整理）` → 插到**标题之前**；
3. 否则追加到文末。

第 2 条很重要：落到纪要段里的引用会在下一次「一键处理」时被整段覆盖（Rust 侧 `upsert_minutes`）。

## 已知限制

- 行内格式（加粗、链接）没有悬浮工具栏：在段里直接写 `**加粗**`、`[文字](url)`，写回后即渲染；
- 未做块拖拽排序、多选块、表格编辑 UI（表格块按原文编辑）；
- 编辑器只用于笔记正文；转写块与纪要段由「一键处理」生成，建议在源码形态里改（或在块里直接改也可以，不影响解析）。
